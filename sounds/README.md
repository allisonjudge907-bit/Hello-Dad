Want **real** fart sounds instead of synthesized ones? Drop audio files in
this folder named:

```
fart1.mp3   (or fart1.wav)
fart2.mp3
...up to fart10
```

The site checks for these automatically when the present is opened. Any it
finds get used (with a random pitch shift each play so repeats sound fresh);
if none are found, it falls back to the built-in Web Audio synthesizer.

## How to add samples

**Easiest way — GitHub web UI:**
1. Go to this `sounds/` folder on github.com
2. Click **Add file → Upload files**
3. Drag your `.mp3`/`.wav` files in, name them `fart1.mp3` etc., commit

**Where to find good ones (free):**
- [freesound.org](https://freesound.org/search/?q=fart) — search "fart",
  filter by Creative Commons 0 license
- Record your own (mouth on arm — the classic technique)

Keep files short (0.5–3 seconds) for best comedic timing.
